    References

    Curated documentation, indexing guides, and practice sandboxes for database administrators. Items marked free can be read or used without cost. Pair this page with Demo Examples.

    Engine Documentation

    Primary manuals for the reference engine (PostgreSQL) and embedded/portable SQL (SQLite).

    ResourceUse it for
    PostgreSQL Documentation freeAuthoritative reference for SQL syntax, EXPLAIN, MVCC, roles, RLS, backup, and replication.
    SQLite Documentation freeReference for local testing, WAL mode, query planner behavior, and portable SQL.
    The Internals of PostgreSQL freeDeep dive into heap pages, MVCC visibility, WAL, and vacuum mechanics.

    Indexing Guides and Practice Sandboxes

    Interactive SQL exercises and practical query-tuning references.

    ResourceUse it for
    Use The Index, Luke! freePractical guide to B-tree indexing, composite key order, joins, and pagination performance.
    PostgreSQL Exercises freeBrowser-based PostgreSQL exercises covering joins, aggregates, CTEs, and window functions.
    SQLBolt freeInteractive lessons for foundational SELECT, filtering, joins, and DDL/DML.
    DB Fiddle freeTest schemas, queries, and execution plans in PostgreSQL or SQLite in the browser.

    Books Worth Borrowing or Buying

    Print references for data modeling, distributed storage, and production reliability.

    • Designing Data-Intensive Applications by Martin Kleppmann: storage engines, transactions, replication, and consensus.
    • Database Internals by Alex Petrov: B-trees, LSM-trees, and distributed database architecture.
    • SQL Antipatterns by Bill Karwin: common schema, query, and indexing mistakes and how to avoid them.
