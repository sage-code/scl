Svelte Roadmap

Svelte is a compiler-first front-end framework that converts components into minimal runtime JavaScript. Its main use case is building fast interactive interfaces with simple reactivity and low conceptual overhead. Its moat is compile-time optimization: less framework runtime in the browser means lean bundles and direct mental models.

Scope: Complete each lesson with runnable examples and architecture notes.
