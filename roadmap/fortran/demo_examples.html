    Fortran Lab Examples

    Twenty-two runnable single-file programs that follow the track's lesson order, grouped by category. Every file is self-contained and fully commented. Run them locally with the compiler listed on the page, or open them in the code viewer — then change one thing and run again. That second run is where the learning happens.

    Foundations

    Hello world, the five intrinsic types with KIND, operator precedence, and the declaration discipline. These four files introduce every value and habit the later demos rely on.

    Crossing the language boundary in both directions: a bind(c) library with its C caller, and the F2PY bridge whose Python driver calls the Fortran kernel every time step.

    How to run them. Compile straight from the demo folder: gfortran -Wall -o demo demo/foundations/01_hello.f90. Demos 5–15 need only gfortran; 16 needs -fopenmp; 17 works with plain gfortran (single image) or -fcoarray=lib; 18 needs mpifort + mpiexec -n 4; the interop pair compile with the commands in their own comments. Larger multi-file study projects follow in Study Projects.
