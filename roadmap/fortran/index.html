Fortran Tutorial

Fortran — born from John Backus’s 1953 IBM team, first compiler shipped 1957 — is the oldest still-active language and the undisputed workhorse of high performance computing. This track teaches modern Fortran through 2023: foundations, data and modules, reliability, the full parallel stack (OpenMP, coarrays, MPI, GPUs), Python integration, and an honest comparison with Rust and Zig.

Scope: Study the lessons in order, compile every example with gfortran, run the lab demos, and keep the official sources from the references page open.
