    Fortran Expressions

    An expression combines values, operators and function calls into one value. Fortran expressions read like mathematics: a = sqrt(b**2 + c**2). This lesson fixes the precedence rules, the dotted logical operators, and the intrinsic functions every program reaches for — including the array-aware behaviour that makes Fortran expressions special.

    Operator precedence

    Precedence is the mathematical hierarchy you already know, with exponents binding tighter than multiplication. Parentheses override everything; when in doubt, add them — the cost is zero and the reader never has to guess. The full order, from tightest to loosest:

    PrecedenceOperatorsMeaning
    1 (tightest)**exponentiation (right-associative)
    2* /multiplication, division
    3+ -addition, subtraction
    4== /= < <= > >=relational comparisons
    5.not.logical negation
    6.and.logical conjunction
    7.or.logical disjunction
    8 (loosest).eqv. .neqv.logical equivalence

    Beware the exponent trap: -2**2 parses as -(2**2) and equals -4, because exponentiation binds tighter than the unary minus. Write (-2)**2 for 4.

    Arithmetic details

    Integer division truncates toward zero: 7/3 is 2, -7/3 is -2. Mixing an integer with a real promotes to real, but only after the integer operation evaluates — 1/2*3.0 is 0.0, not 1.5. Modern Fortran 2023 added division that keeps the fractional part (7./3. style), and the safe habit stands: put a decimal point (and a kind suffix) on at least one operand of every real division.

    Logical operators and truth tables

    Logical expressions combine logical values with the dotted operators. Fortran spells them out because && and || were invented decades later. The useful set: .not. (negation), .and., .or., plus .eqv. (true when both sides are equal) and .neqv. (exclusive or). There is no short-circuit guarantee — both sides of .and./.or. are evaluated, so do not rely on a right-hand test to guard an out-of-bounds expression.

    logical :: a, b
a = .true.                      ! spelled out, no 1/0
b = .false.
print *, a .and. b              ! .false.
print *, a .or. b               ! .true.
print *, .not. a                ! .false.
print *, a .eqv. b              ! .false. — sides differ
print *, a .neqv. b             ! .true.  — sides differ

    Array expressions

    Here Fortran leaves its peers behind. An array name in an expression means the whole array: operations are element-wise, shapes must agree, and the result is an array of the same shape. This is how the overview lesson's one-line c = sqrt(a) + b replaced a loop — the compiler expands it into a loop it can then parallelize or vectorize. Scalars broadcast: 2.0_real64 * a doubles every element.

    program array_exprs
  use iso_fortran_env, only: real64
  implicit none
  real(real64) :: x(4), y(4), z(4)
  x = [1.0_real64, 2.0_real64, 3.0_real64, 4.0_real64]  ! array constructor
  y = 2.0_real64 * x                  ! broadcast a scalar
  z = max(x, y)                       ! element-wise maximum
  print '(4f6.1)', z                  ! prints 2.0 4.0 6.0 8.0
end program array_exprs

    A masked expression even picks per-element: where (x > 2.0_real64) z = x assigns only where the mask is true — a whole if loop in one guarded statement, covered again in the arrays lesson.

    The intrinsic function family

    Fortran's built-in functions are organized by job, and most accept real and integer arguments with automatic kind promotion. The groups you will use daily:

    • Math: abs, sqrt, exp, log, mod, sign, floor, ceiling, nint
    • Trigonometry: sin cos tan and inverses asin acos atan atan2 (radians by default, sin_deg etc. in F2023)
    • Array reductions: sum, product, maxval, minval, dot_product, matmul — computed in optimal order internally
    • Character: len, trim, adjustl, index, repeat (the strings lesson)
    • Bits and numbers: iand, ior, ishft, huge, tiny, epsilon, random_number
    program intrinsics
  use iso_fortran_env, only: real64
  implicit none
  real(real64) :: angles(3), sines(3)
  angles = [0.0_real64, 0.5_real64, 1.0_real64]   ! radians
  sines = sin(angles)                              ! element-wise
  print *, sum(sines), maxval(sines), epsilon(1.0_real64)
end program intrinsics

    Every intrinsic has one canonical spelling and a precise argument contract. When a call looks odd — epsilon takes a type prototype, not a value — the official intrinsic reference (gfortran's HTML docs, linked on the references page) settles it in seconds.
