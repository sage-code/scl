    Rust Demo Examples

    Practice programs, one file each. Every demo is self-contained, commented, and uses only the standard library — so nothing needs downloading: compile with rustc and run.

    How to use: click View to open a file in the code viewer, read its comments, download it, then run it on your machine. Most demos are plain binaries; the tests demo (#20) needs --test.

    rustc 01_hello.rs && ./01_hello          # compile and run a demo
rustc --test 20_testing.rs -o 20_testing   # compile unit tests
./20_testing
