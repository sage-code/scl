Shell Programming

Bash is a domain specific programming language. It is the default scripting language on UNIX systems. It is open source and available on FreeBSD, Mac OS and Linux. This should be your first programming language to master system programming and the Linux command line. Bash is the successor of Shell script, therefore it is also called Shell scripting language.

Scope: Study the topics in order, run the examples in a real terminal, and be careful with whitespace and quotes along the way.
