Bash Scripting

A shell is the program that turns typed commands into actions: it reads a line, interprets it, runs it, and repeats. Bash (the Bourne Again SHell) is the default shell on most Linux systems and macOS, and it is the language behind build scripts, CI/CD pipelines, containers, and server automation. This track removes the mystery around the shell, compares the major interpreters, and teaches you to write real Bash on both Linux and Windows.

Scope: Study the topics in order, run every example in a real terminal, and adopt the robust-scripting habits from Phase 5 before you automate anything important.
