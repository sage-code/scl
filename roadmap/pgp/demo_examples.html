    PGP Demo Examples

    Each paradigm lesson names a small set of representative languages — the ones that make that paradigm's ideas most visible. Every one of those languages gets a short, self-contained example here, syntax-highlighted for that specific language in the code viewer, so you can see the paradigm's shape in real code without installing anything.

    How to use: click View to open a file in the code viewer and read its comments. These are teaching snippets, not runnable projects — most need only a standard interpreter/compiler for that language if you want to try them yourself (a Prolog demo needs SWI-Prolog, a Lisp demo needs any Common Lisp, and so on).

    Practice move: pick one demo whose language you've never touched — Prolog and Smalltalk are the least familiar to most readers — and try to explain, line by line, what makes it feel different from the language you use daily. That difference is the paradigm.
