Lab Topics

    Control Flow

    Control flow determines execution order in your app. Clear branching logic reduces bugs.

    Conditions

    if (isLoggedIn) {
  showDashboard();
} else {
  showLogin();
}

    Switch usage

    switch (theme) {
  case "dark": applyDarkTheme(); break;
  case "light": applyLightTheme(); break;
  default: applySystemTheme();
}

    Loops

    • for for index control
    • for...of for iterables
    • while for state-based loops

    Guard clauses

    Return early from functions when input is invalid. This keeps nested logic shallow.

    Practice

    Create a menu renderer that branches on user role and loops through visible actions.
