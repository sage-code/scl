    Syntax and Expressions

    JavaScript syntax defines how code is written. Expressions produce values; statements perform actions.

    Basic statements

    "use strict";

let total = 0;
total = total + 5;
console.log(total);

    Operators

    • Arithmetic: +, -, *, /, %
    • Comparison: ===, !==, >, <, >=, <=
    • Logical: &&, ||, !

    Strict mode

    Use "use strict"; in learning code to catch silent mistakes early.

    Common mistakes

    1. Using = instead of === in conditions.
    2. Forgetting semicolons in chained one-line statements.
    3. Mixing strings and numbers without explicit conversion.
