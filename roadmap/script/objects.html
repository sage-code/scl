    Objects and Arrays

    Most front-end state is modeled with nested objects and arrays.

    Object basics

    const user = {
  name: "Maya",
  role: "student",
  isActive: true
};

console.log(user.name);

    Array basics

    const tags = ["html", "css", "javascript"];
console.log(tags[0]);

    Destructuring

    const { name, role } = user;
const [firstTag] = tags;

    Immutable updates with spread

    const updatedUser = { ...user, isActive: false };
const extendedTags = [...tags, "accessibility"];
