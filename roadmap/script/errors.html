    Errors and Bug Fixing

    Debugging is a skill, not luck. Build a repeatable process and follow evidence.

    Common error types

    • Syntax errors
    • Reference/type errors
    • Logic errors (runs but wrong output)
    • Async timing issues

    Debug workflow

    1. Reproduce the bug reliably.
    2. Read console and stack trace first.
    3. Inspect variables at failure point.
    4. Fix the root cause, not symptoms.
    5. Retest related flows.

    Defensive coding

    function safeUpper(text) {
  if (typeof text !== "string") return "";
  return text.toUpperCase();
}

    Practice

    Intentionally create three bugs in a small app, then fix them using the same workflow.
