    DOM and Website Interactivity

    Front-end JavaScript mainly connects user actions to DOM updates.

    Select elements

    const button = document.querySelector("#save-btn");
const status = document.querySelector("#status");

    Events and handlers

    button.addEventListener("click", () => {
  status.textContent = "Saved";
});

    Class and state updates

    panel.classList.toggle("is-open");

    DOM best practices

    • Cache selectors used often.
    • Avoid unnecessary full re-renders.
    • Prefer event delegation for repeated items.
