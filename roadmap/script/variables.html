Lab Topics

    Variables and Scope

    Use const by default. Use let when reassignment is required. Avoid var in modern front-end code.

    Declaration rules

    const siteName = "Sage-Code";
let clickCount = 0;

clickCount += 1;

    Primitive types

    • string
    • number
    • boolean
    • null
    • undefined
    • symbol
    • bigint

    Scope basics

    Variables declared with let and const are block-scoped.

    if (true) {
  const status = "active";
  console.log(status);
}
// console.log(status); // ReferenceError

    Naming and readability

    1. Use descriptive names.
    2. Avoid abbreviations unless standard.
    3. Keep naming style consistent.

    Practice

    Create a small profile object and log values with template strings.
