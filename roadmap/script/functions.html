    Functions

    Functions package reusable behavior. They are core to event handlers, validation logic, and UI updates.

    Declarations and expressions

    function sum(a, b) {
  return a + b;
}

const multiply = function (a, b) {
  return a * b;
};

    Arrow functions

    const formatName = (first, last) => `${first} ${last}`;
const square = n => n * n;

    Parameters and return values

    • Use default values for optional input.
    • Return predictable types.
    • Avoid hidden side effects in utility functions.

    Callbacks and events

    button.addEventListener("click", () => {
  updateCounter();
});
