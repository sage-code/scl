    Framework Guidance

    This roadmap teaches vanilla front-end JavaScript. Frameworks are a separate next step.

    When to move to a framework

    • You can build small apps with plain JS and DOM APIs.
    • You understand state, events, and component thinking.
    • You can debug browser code with confidence.
