    Collections and Iteration

    Collections help manage repeated data. Iteration patterns let you transform and filter that data cleanly.

    Array methods

    const prices = [12, 8, 20];
const discounted = prices.map((p) => p * 0.9);
const expensive = discounted.filter((p) => p > 10);
const total = expensive.reduce((sum, p) => sum + p, 0);

    Map and Set

    • Map stores key-value pairs with any key type.
    • Set stores unique values.

    Iteration style

    Prefer declarative methods like map, filter, and find for readability.

    Performance note

    For most UI tasks, readability matters more than micro-optimizations. Optimize only when profiling shows a bottleneck.
