Lab Topics

    Styling Strategy

    Styling is architecture: naming, tokens, and boundaries affect long-term speed and consistency.

    Style approaches

    • Global styles for shared primitives.
    • Scoped modules for component-specific styles.
    • Design tokens for consistent spacing, colors, and type.

    Naming conventions

    Use explicit class naming patterns that communicate role and context to reduce ambiguity.

    Responsive rules

    Design mobile-first and verify key breakpoints during feature development, not at release time.

    Accessibility and styling

    Preserve focus visibility, color contrast, and reduced-motion support in every interactive component.

    Practice

    Refactor a page to use design tokens, responsive layout rules, and accessible focus treatments.
