Carbon Tutorial

Carbon is a statically typed programming language that focuses on safety and performance. It is a third generation language with features inspired from C++. It was created by Chandler Carruth who works for Google. Carbon is an experimental, general-purpose programming language.

Scope: Study the topics in order, compile each example, and use the external references for authoritative depth.
