Assembly Tutorial

Assembly is the lowest-level language a human still writes by hand: one line of source maps to one machine instruction. It is not portable — every processor family has its own instruction set and its own dialect. This track teaches one dialect thoroughly (x86-64 with NASM) and then shows you the same ideas in ARM, RISC-V, and WebAssembly, so you can read the assembly behind any compiler.

Scope: Study the topics in order, assemble and run every example, and always connect the mnemonic to the register and flag it actually changes on your target CPU.
