    ARM64 Examples

    The same ideas in a RISC dialect. Assemble on an ARM64 Linux host with as, or cross-assemble with aarch64-linux-gnu-as and run under QEMU (qemu-aarch64 ./app). CPUlator runs them in the browser with no toolchain at all.

    How to use a demo: open it in the code viewer, read the comments top to bottom, download it, assemble it, run it — then break it on purpose. Change a size qualifier, swap a signed jump for an unsigned one, leave out a cqo. Watching the program fail in a predictable way is how the rules become permanent.

    What to Do Next

    Work the list in order. Each demo file ends with a short Try this comment suggesting one deliberate modification; do them all before moving on to the Study Projects page.

    • Assemble and run every x86-64 demo on Linux or WSL2.
    • Assemble and run at least two ARM64 demos in CPUlator or under QEMU.
    • Compare the x86-64 array loop (14) with the ARM64 one (20) — the addressing is where the two dialects differ most.
