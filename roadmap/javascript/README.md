# javascript

Sage-Code JavaScript tutorial — `/roadmap/javascript/` (renamed from `roadmap/script`;
old URLs 301-redirect in `vercel.json`).

## Structure

- `index.html` — phase dashboard (7 phases, topics 01–29) with progress tracking.
- `getting-started.html` + `html-and-js.html` — zero-knowledge on-ramp: run your first
  program, wire JavaScript into an HTML page, and the study loop used across the track.
- Lesson pages `<topic>.html` + sidebar sidecar `data/<topic>.json`.
- `demo/foundations/` — numbered single-file demos; browser demos are self-contained
  (previewable), `.js` demos run with `node`.
- `samples.html` — study projects; `references.html` — categorized references.
- Track-specific SVG diagrams in `img/` (dark-theme style spec, `manual/ARCHITECTURE.md`).
