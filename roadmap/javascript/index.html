JavaScript Roadmap

JavaScript is the language of the web platform: it runs in every browser, and with Node.js it runs servers, desktops, and embedded devices. Its main use case is behavior: user events, network calls, state updates, and dynamic rendering, coordinated through a single-threaded event loop. Its depth is easy to underestimate: real expertise means the type system's sharp edges, the runtime's memory model, and true parallelism with workers and shared memory.

Status: Phases 1–2 (lessons 01–13) are fully written at the new standard: every example runnable, with expected output, contraexamples, and diagrams. Phases 3–7 are next; their pages still show outlines.
Scope: Study the topics in order. For every example, follow the study loop from lesson 01: type it by hand, predict the output, run it, break it on purpose, then fix it. Copy-paste teaches nothing.
