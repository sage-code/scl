Fluid type with clamp()

Drag the window edge slowly: this heading grows and shrinks smoothly, never below 1.75rem and never above 3.25rem — no media query involved.

Fixed 2rem: never adapts

clamp(1.35rem, 1.1rem + 1.5vw, 2rem): adapts inside bounds

At a large window the clamped heading exceeds the fixed one; below 1.35rem it would stop shrinking. The bounds are the design decision.
