    Box Model and Layout Basics

    Every element is a box. When layout looks wrong, inspect width, padding, border, and margin before trying anything else.

    Four box areas

    Content, padding, border, and margin.

    • Content: where text or media appears.
    • Padding: inner spacing between content and border.
    • Border: visible edge of the element.
    • Margin: outer spacing between neighboring elements.

    Sizing models

    Most teams prefer border-box because width calculations stay predictable.

    /* Recommended baseline */
*, *::before, *::after {
  box-sizing: border-box;
}

.card {
  width: 320px;
  padding: 1rem;
  border: 1px solid #334155;
  margin-bottom: 1rem;
}

    Spacing system

    Use a small scale and reuse it everywhere:

    :root {
  --space-1: 0.25rem;
  --space-2: 0.5rem;
  --space-3: 1rem;
  --space-4: 1.5rem;
}

.section { margin-block: var(--space-4); }
.card { padding: var(--space-3); }

    Layout tools

    Tool Best for Starter property
    Flexbox One-dimensional alignment (row or column) display: flex;
    Grid Two-dimensional page sections display: grid;
    Positioning Badges, overlays, anchored UI position: relative/absolute;

    Quick debug routine

    1. Open browser dev tools and inspect computed box model.
    2. Temporarily add border colors to see boundaries.
    3. Check box-sizing, width constraints, and margin collapse.
    4. Convert ad-hoc spacing to your spacing scale.
