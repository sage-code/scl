    Typography and Readability

    Good typography makes technical content easier to read, scan, and remember. Small spacing decisions have a big impact.

    Core properties

    Property Why it matters Common starter value
    font-family Controls tone and readability system-ui, sans-serif
    font-size Sets base reading size 1rem for body
    line-height Improves line scanning 1.5 to 1.7
    letter-spacing Fine-tunes dense text 0.01em for headings
    font-weight Creates hierarchy 400 body, 600+ headings

    Baseline stylesheet

    :root {
  font-size: 16px;
}

body {
  font-family: system-ui, -apple-system, "Segoe UI", sans-serif;
  line-height: 1.6;
  color: #e5e7eb;
}

h1, h2, h3 {
  line-height: 1.25;
  letter-spacing: 0.01em;
  margin-bottom: 0.5rem;
}

p {
  margin-bottom: 1rem;
  max-width: 70ch;
}

    Units that scale

    • px: fixed size, useful for borders and fine control.
    • rem: based on root font size, ideal for consistent scaling.
    • em: based on parent element, useful for component-relative sizing.
    • %: relative to parent, useful for fluid containers.

    Font loading and performance

    Web fonts improve branding but increase requests. Keep the load efficient:

    1. Use one or two font families max.
    2. Load only required weights.
    3. Use display=swap to avoid invisible text during load.
    4. Prefer local/system stack unless custom branding is required.
    <link
  href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;600&display=swap"
  rel="stylesheet">

    Quick checklist

    • Body text is readable on mobile without zoom.
    • Line length is roughly 45 to 75 characters.
    • Heading levels are visually distinct.
    • Contrast between text and background is strong.
