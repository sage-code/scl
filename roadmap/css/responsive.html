    Responsive Design

    Responsive design means one codebase adapts to phones, tablets, and desktops without breaking readability.

    Mobile-first workflow

    1. Design the smallest layout first.
    2. Add spacing and typography that works at narrow widths.
    3. Use media queries to enhance for larger screens.
    4. Test on real devices, not only resized desktop windows.

    Media query pattern

    /* Base styles: mobile */
.layout {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

/* Tablet and up */
@media (min-width: 768px) {
  .layout {
    grid-template-columns: 1fr 1fr;
  }
}

/* Desktop and up */
@media (min-width: 1024px) {
  .layout {
    grid-template-columns: 2fr 1fr;
  }
}

    Fluid sizing

    Prefer relative units over fixed pixels for scalable UI:

    • Use max-width and percentages for containers.
    • Use rem for typography and spacing.
    • Use clamp() for smooth font scaling.
    .page {
  width: min(92%, 72rem);
  margin-inline: auto;
}

h1 {
  font-size: clamp(1.5rem, 2vw + 1rem, 2.5rem);
}

    Responsive checklist

    Check Target
    Touch targets At least 44px by 44px
    Body text size At least 16px equivalent
    No horizontal scroll All common phone widths
    Image behavior max-width: 100%;

    Debugging routine

    1. Use browser device emulation to inspect 360px, 768px, and 1280px widths.
    2. Inspect overflow on offending elements.
    3. Check fixed widths, large margins, and non-wrapping text.
    4. Re-test landscape orientation.
