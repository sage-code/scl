    Animations and Transitions

    Use motion to clarify state changes, not as decoration noise. Fast and subtle transitions usually feel best.

    Transitions first

    Start with transitions because they are simple and excellent for hover, focus, and active states.

    .btn-primary {
  background: #2563eb;
  transform: translateY(0);
  transition: background-color 180ms ease, transform 180ms ease;
}

.btn-primary:hover,
.btn-primary:focus-visible {
  background: #1d4ed8;
  transform: translateY(-2px);
}

    Keyframes for sequences

    Use keyframes when you need multiple animation stages.

    @keyframes fade-slide-in {
  from {
    opacity: 0;
    transform: translateY(12px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.panel {
  animation: fade-slide-in 260ms ease-out;
}

    Core animation properties

    Property Role Example
    animation-name Keyframe identifier fade-slide-in
    animation-duration How long it runs 260ms
    animation-timing-function Speed curve ease-out
    animation-iteration-count How many times 1 or infinite

    Accessibility and performance

    • Keep important transitions below 300ms.
    • Animate transform and opacity when possible.
    • Avoid heavy infinite animations on large areas.
    • Respect user preference with reduced motion.
    @media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}

    Practice task

    Create a card that fades in on load and slightly lifts on hover. Keep both effects subtle and test with reduced motion enabled.
