    CSS References

    This track teaches the language; it is not the specification. The categorized references below are the sources to keep open while you work — official standards, documentation, compatibility data, validators, and free practice environments. Every link is free to use.

    Specifications and standards

    ReferenceWhat it isBest forLink
    W3C CSS Snapshot The index of CSS specifications that define the web platform's CSS Seeing what "CSS" officially consists of w3.org/TR/CSS
    CSSWG Editor Drafts The CSS Working Group's current specification drafts Reading a module in its most current form drafts.csswg.org
    cssdb A database of CSS features and their standardization stages Judging whether a modern feature is safe to ship cssdb.org
