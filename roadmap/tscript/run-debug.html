    Run and Debug TypeScript

    Debugging TypeScript effectively means debugging source, not output JavaScript.

    Execution modes

    • Type check only: tsc --noEmit
    • Continuous checks: tsc --watch
    • Bundler-driven builds for production delivery

    Source maps

    Enable source maps so breakpoints map back to .ts source files in browser DevTools.

    Debugging playbook

    1. Reproduce bug with deterministic steps.
    2. Set breakpoints at typed boundaries (API parsing, state transitions).
    3. Inspect narrowed types and runtime values together.
    4. Fix root cause and rerun type-check plus tests.

    CI quality gates

    Required pipeline stages: lint, type-check, unit tests, and production build. Fail fast on type regressions.

    Practice

    Resolve one runtime state bug and one contract bug using the same debugging checklist.
