Lab Topics

    Run and Debug TypeScript

    Enterprise debugging uses source maps, repeatable scripts, and strict diagnostics gates.

    Compiler modes

    • tsc --noEmit for type checks
    • tsc --watch for iterative dev feedback
    • Bundler integration for production pipelines

    Source maps

    Enable source maps so browser breakpoints point to .ts files, not compiled output.

    Debug loop

    1. Reproduce bug.
    2. Set breakpoint in TypeScript source.
    3. Inspect typed state and branch logic.
    4. Fix, recheck types, and retest.

    CI quality gates

    Run lint + type-check + test stages in CI and fail on regression.

    Practice

    Debug one runtime issue and one type-level issue using the same repeatable checklist.
