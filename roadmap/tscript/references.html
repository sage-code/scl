    References and Standards

    Enterprise TypeScript quality depends on shared references and documented standards, not individual preferences.

    Official documentation

    • TypeScript Documentation
    • TSConfig Reference
    • TypeScript Playground

    Team standards

    • Strict mode required in all packages.
    • No unchecked any in production paths.
    • Typed API boundaries and explicit error contracts.
    • Automated checks in CI for lint, types, and tests.

    Code review checklist

    1. Are nullable values handled explicitly?
    2. Do interfaces reflect real backend contracts?
    3. Are unsafe assertions justified and minimal?
    4. Are advanced types readable to the team?

    Migration plan for legacy JavaScript

    Adopt gradually: start with allowJs, type hot paths first, then enforce strict mode module by module.

    Practice

    Write a one-page team TypeScript standard and apply it to one feature PR with measurable improvements.
