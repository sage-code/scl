    Generics for Reusable Components

    Generics preserve type information across reusable abstractions and eliminate duplicate code.

    Generic collections

    function firstItem<T>(items: T[]): T | undefined {
  return items[0];
}

    Constraints

    function pluckId<T extends { id: string }>(value: T): string {
  return value.id;
}

    UI generic patterns

    Use generics for table rows, form schemas, and repository/client adapters.

    Inference guidelines

    Prefer inferred generic arguments unless clarity requires explicit type parameters.

    Practice

    Build a generic pagination helper for API lists with typed result metadata.
