    Generics for Reuse

    Generics let you build reusable systems without giving up type precision.

    Generic foundations

    function first<T>(items: T[]): T | undefined {
  return items[0];
}

    Constraints and safety

    type HasId = { id: string };

function byId<T extends HasId>(list: T[], id: string): T | undefined {
  return list.find(item => item.id === id);
}

    UI generic patterns

    • Generic table rows and column definitions.
    • Generic async state wrappers.
    • Generic repository adapters for API resources.

    Inference strategy

    Prefer inference first. Provide explicit type arguments only when readability or correctness requires it.

    Common generic smells

    1. Overly complex generic signatures nobody can read.
    2. Unbounded generics where constraints are required.
    3. Using generics where a specific type is clearer.

    Practice

    Create a generic paginated response model and reuse it across three different API resource types.
