    Core Types and Narrowing

    Type safety starts here. If you master core types and narrowing, advanced TypeScript becomes much easier.

    1. Primitive types

    let username: string = "maya";
let score: number = 42;
let active: boolean = true;
let nothing: null = null;
let missing: undefined = undefined;

    2. Union types

    type Id = string | number;
let currentId: Id = "u-100";
currentId = 100;

    Union types model real-world variability while preserving safety.

    3. Literal types and enums-like patterns

    type Status = "idle" | "loading" | "success" | "error";
let state: Status = "idle";

    4. Narrowing basics

    function normalize(value: string | number): string {
  if (typeof value === "number") {
    return value.toFixed(2);
  }
  return value.trim();
}

    5. Type guards in API flows

    type ApiResult =
  | { ok: true; data: string[] }
  | { ok: false; error: string };

function isSuccess(result: ApiResult): result is { ok: true; data: string[] } {
  return result.ok;
}

    6. unknown vs any

    • any: disables safety.
    • unknown: requires checks before use.
    function parseInput(input: unknown): string {
  if (typeof input === "string") return input;
  return "";
}

    7. Readonly and as const

    const roles = ["admin", "editor", "viewer"] as const;
type Role = typeof roles[number];

const config: Readonly<{ apiUrl: string }> = { apiUrl: "/api" };

    8. Nullable values in UI code

    Always model nullable values explicitly, especially for async-loaded state and optional user data.

    9. Common errors

    1. Overusing as to silence errors.
    2. Ignoring null checks in rendering code.
    3. Using broad unions without narrowing strategy.

    10. Practice

    Implement typed state for a profile page: idle | loading | success | error, and render each state safely.
