    Core Types and Narrowing

    You cannot scale front-end architecture without understanding type narrowing and null safety deeply.

    Primitive and union types

    let total: number = 0;
let title: string = "Dashboard";
let visible: boolean = true;
let selectedId: string | null = null;

    Type guards in real code

    type ApiResult = { ok: true; data: string[] } | { ok: false; error: string };

function render(result: ApiResult) {
  if (result.ok) {
    return result.data.join(", ");
  }
  return `Error: ${result.error}`;
}

    unknown at external boundaries

    Use unknown for raw inputs from network, storage, or window globals. Narrow before use and avoid direct casts.

    Literal and readonly patterns

    const roles = ["admin", "editor", "viewer"] as const;
type Role = typeof roles[number];

    Common mistakes

    1. Using any to silence compiler warnings.
    2. Using non-null assertion (!) everywhere.
    3. Trusting API data without runtime checks.
