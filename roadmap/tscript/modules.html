Lab Topics

    Modules and Project Boundaries

    Good module boundaries reduce coupling and increase delivery speed for large front-end teams.

    Import and export patterns

    Use explicit named exports for shared APIs and reserve default exports for deliberate ergonomic cases.

    Barrel usage

    Barrels can improve discoverability but can also hide dependency direction. Use with discipline.

    Feature slicing

    Organize modules by feature domain, not by file type, to support product-oriented ownership.

    Public vs internal APIs

    Define stable public module contracts and avoid deep imports into internals.

    Practice

    Refactor a small app into feature modules with typed public exports only.
