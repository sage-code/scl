Lab Topics

    Modules and Boundaries

    A scalable front-end app is a set of small, coherent modules with strict public contracts.

    Export strategy

    Prefer named exports for discoverability and refactoring safety across large codebases.

    Feature slicing

    src/
  features/
    billing/
      api/
      domain/
      ui/
      index.ts
    auth/
      ...

    Public module API

    Each feature should expose a stable entry point. Avoid deep imports into private files.

    Dependency direction

    UI may depend on domain contracts, but domain should not depend on UI rendering details.

    Boundary tests

    Test exported functions and contracts, not internal file layout.

    Practice

    Refactor one feature into a clean module with index.ts as the only public API.
