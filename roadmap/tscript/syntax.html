    Syntax Fundamentals

    This is a complete beginner lesson. We start with writing rules, then statements, then operators and symbols used in production TypeScript.

    1. Comments and style

    // Single-line: explain one decision

/* Multi-line:
   explain non-obvious business rules */

    Professional rule: comments explain why, code explains what.

    2. Declarations and type annotations

    const appName: string = "Sage Portal";
let retries: number = 3;
let isEnabled: boolean = true;

// Avoid var in modern code
var legacy: boolean = false;
    • const: cannot be reassigned.
    • let: can be reassigned.
    • :: attaches a type annotation.
    • =: assignment operator.
    • ;: statement terminator (recommended for consistency).

    3. Statements and control flow

    if (retries > 0) {
  console.log("Retrying...");
} else {
  console.log("No retries left");
}

for (let i = 0; i < 3; i++) {
  console.log(i);
}

switch (appName) {
  case "Sage Portal":
    console.log("Known app");
    break;
  default:
    console.log("Unknown app");
}

    Essential statements: if, switch, for, for...of, while, return, throw, try/catch/finally.

    4. Operators basics

    Arithmetic operators

    const sum = 2 + 2;
const diff = 5 - 2;
const product = 3 * 4;
const quotient = 12 / 3;
const remainder = 10 % 3;

    Comparison operators

    const isEqual = 10 === 10;
const isDifferent = 10 !== 5;
const isGreater = 10 > 8;
const isAtMost = 10 <= 10;

    Logical operators

    const hasToken = true;
const isAdmin = false;

const canAccess = hasToken && isAdmin;
const canRead = hasToken || isAdmin;
const isBlocked = !hasToken;

    Assignment operators

    let count = 10;
count += 2;
count -= 1;
count *= 2;
count /= 2;

    5. Nullish and optional syntax

    type User = { name?: string };
const user: User = {};

const name = user.name ?? "Anonymous"; // ?? nullish coalescing
const len = user.name?.length;          // ?. optional chaining

    Use these two operators everywhere optional data appears (forms, APIs, local storage).

    6. TypeScript-specific symbols and keywords

    • | union type: string | number.
    • & intersection type: A & B.
    • as type assertion: value as HTMLElement.
    • keyof property-name union of a type.
    • typeof type from runtime value.
    • extends generic constraint or inheritance.
    • infer type extraction in conditional types.
    type Account = { id: string; active: boolean };
type AccountKey = keyof Account; // "id" | "active"

function read<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

    7. Punctuation reference

    • { } block/object
    • ( ) grouping/function parameters
    • [ ] arrays/indexing
    • < > generics
    • , separators
    • . property access
    • ... spread/rest
    • => arrow functions
    • ? optional property/ternary

    8. Module import and export syntax

    // logger.ts
export function logInfo(message: string): void {
  console.log(`[INFO] ${message}`);
}

// app.ts
import { logInfo } from "./logger";
logInfo("App started");
