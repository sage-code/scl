Lab Topics

    Syntax Fundamentals

    This lesson starts from zero. You will learn TypeScript writing rules, statement forms, operators, and symbols used in professional codebases.

    1. Comments

    Comments explain intent. Use concise comments for business decisions and edge cases.

    // Single-line comment

/*
  Multi-line comment
  Use for short blocks, not for disabling large code regions.
*/

    2. Declarations and Semicolons

    TypeScript supports JavaScript declaration forms and adds type annotations.

    const projectName: string = "Sage Frontend";
let activeUsers: number = 120;
var legacyFlag: boolean = false; // avoid var in modern code

activeUsers += 1;
    • const: value reference cannot be reassigned.
    • let: reassignable variable.
    • :: type annotation symbol.
    • ;: statement terminator (recommended for consistency).

    3. Core Statement Types

    if (activeUsers > 100) {
  console.log("High traffic");
} else {
  console.log("Normal traffic");
}

for (let i = 0; i < 3; i++) {
  console.log(i);
}

while (activeUsers > 0) {
  activeUsers--;
  if (activeUsers === 10) break;
}

    Important statements to master: if, switch, for, for...of, while, break, continue, return, throw, try/catch/finally.

    4. Operators Explained

    Arithmetic operators

    const sum = 2 + 3;    // + addition
const diff = 7 - 4;   // - subtraction
const prod = 3 * 5;   // * multiplication
const div = 10 / 2;   // / division
const rem = 10 % 3;   // % remainder

    Assignment operators

    let count = 5;
count += 2;
count -= 1;
count *= 3;
count /= 2;

    Comparison operators

    const a = 10;
const b = "10";

console.log(a === Number(b)); // strict equality
console.log(a !== 5);         // strict inequality
console.log(a > 8);
console.log(a <= 10);

    Logical operators

    const isAdmin = true;
const isOwner = false;

const canEdit = isAdmin || isOwner; // || OR
const canDelete = isAdmin && isOwner; // && AND
const blocked = !isOwner; // ! NOT

    Nullish and optional operators

    type Profile = { name?: string };
const profile: Profile = {};

const name = profile.name ?? "Anonymous";  // ?? nullish coalescing
const length = profile.name?.length;        // ?. optional chaining

    5. TypeScript Type Operators and Symbols

    • : annotation: value: string.
    • | union: string | number.
    • & intersection: A & B.
    • as assertion: value as HTMLElement.
    • keyof: union of property names.
    • typeof (type context): infer type from value.
    • extends: generic constraints and inheritance.
    • infer: captures a type variable in conditional types.
    type User = { id: string; name: string };
type UserKey = keyof User; // "id" | "name"

function pluck<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

    6. Punctuation and Structural Symbols

    • { }: block/object boundaries.
    • ( ): function params and grouping.
    • [ ]: arrays/index access.
    • < >: generic arguments.
    • ,: separators.
    • .: property access.
    • ...: rest/spread syntax.
    • =>: arrow function.
    • ?: optional property or ternary operator.
    const nums = [1, 2, 3];
const copy = [...nums, 4];

const format = (v: number): string => `${v}`;

type ApiResponse = {
  data?: string[];
};

    7. Module Syntax

    // math.ts
export function add(a: number, b: number): number {
  return a + b;
}

// app.ts
import { add } from "./math";
console.log(add(2, 3));

    8. Professional Syntax Checklist

    1. Prefer const, then let.
    2. Use strict equality ===.
    3. Avoid implicit any.
    4. Use optional chaining and nullish coalescing intentionally.
    5. Keep functions short and typed at boundaries.

    9. Step-by-Step Practice

    1. Create variables with explicit types.
    2. Write one function with typed params and return type.
    3. Add if/else and loop control statements.
    4. Use ?? and ?. on optional data.
    5. Split logic into two modules and import/export correctly.
