    Ada Lab Examples

    Fifteen runnable Ada programs that follow the track's lesson order, grouped by phase. Every file is self-contained and fully commented. Compile them with GNAT (gnatmake file.adb — see the run notes at the bottom) or open them in the code viewer and change one thing, then compile again. That second run is where the learning happens.

    How to run them. Compile straight from the demo folder: gnatmake demo/foundations/01_hello.adb then ./01_hello. The multi-file package pair compiles together: gnatmake demo/modular/12_package_main.adb (GNAT finds the spec and body automatically). Demos 3–14 need only GNAT; 17's delays make the interleaving visible; 18 needs any GNAT with the standard library. Larger multi-file study projects are on the Study Projects page.
