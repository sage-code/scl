    Ada Basics

    Here is a step-by-step list of basic concepts in Ada to learn:

    1. Overview - Language history, main features, relevance and job prospect considerations.

    2. Curriculum - this is the current article, it enumerates basic and key topics for understanding Ada fundamentals.

    3. Syntax - General syntax rules, comments, symbols and expressions.

    4. Data types - Built-in types like integer, float, boolean. User-defined types like enumerations and subtypes.

    5. Expressions - Data literals, symbols, operators, parenthesis, character encoding, and precedence of operators.

    6. Conditional statements - logic expressions, and control flow statements (if/else & case).

    7. Loops - for, while, loop. Exiting loops using exit and exit when.

    8. Subprograms - Overloading subprograms. Default arguments.

    9. Arrays - One-dimensional and multi-dimensional arrays. Array manipulations.

    10. Packages - Declaring packages. Package level variables and procedures.

    11. Records - Declaring record types. Accessing and updating record fields.

    12. Exceptions - Declaring exceptions. Raising and handling exceptions.

    13. String handling - Declaring string types. String manipulations like concatenation, comparison etc.

    14. Enumerations - Declaring enumeration types. Enumeration literals.

    15. Input/Output - Reading from and writing to files, keyboard and screen.
