DSA Roadmap

Data structures and algorithms are how engineers think about problems: choose a representation, design a procedure, prove it correct, and predict its cost. This roadmap teaches that thinking in Go, from a first loop invariant to production structures such as LRU caches and concurrent maps, with small examples in every lesson and larger runnable demos in the code viewer.

Scope: Five phases from beginner to expert. Study the lessons in order, run every demo locally with go run file.go (Go 1.23 or newer), and complete each lesson's Practice Lab before moving on.
