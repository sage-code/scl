SQL & PL/SQL Tutorial

Creating and maintaining relational databases requires SQL. This is a 5th generation, declarative, domain specific programming language. It stands for Structured Query Language. You can use SQL with a CLI app or you can embed SQL in application development. PL/SQL adds full procedural power on top of SQL.

Scope: Study the lessons in order, practice each query in your database, and revisit the index for targeted reference.
