    Elixir Lab Examples

    Thirty-six runnable single-file Elixir scripts that follow the track's lesson order, grouped by phase. Every file is self-contained and fully commented. Run them with elixir demo/<group>/NN_name.exs, or open them in the code viewer and change one thing, then run again — that second run is where the learning happens.

    How to run them. Stdlib demos need nothing but Elixir: elixir demo/core/06_pattern_matching.exs. Ecosystem demos (31–34) start with Mix.install/2 and fetch their dependencies from Hex on first run. Demos 35–36 need a PostgreSQL service (35) or a release build (36) and are written to be read and studied in the viewer. Larger multi-file study projects are on the Study Projects page.
