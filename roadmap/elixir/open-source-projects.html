    How to Read Them

    1. Start at the behaviour. Find the use ... or @behaviour and read the callbacks first — they are the contract.
    2. Read the tests before the source. Tests are executable documentation of intent.
    3. Trace one request. Pick the entry function and follow the data; note every :telemetry event on the way.
    4. File an issue, not a rewrite. The point is to study decisions, not to judge them from scratch.
