    C Demo Examples

    Practice programs, one file each. Every demo is self-contained, commented, and free of unsafe legacy functions. Compile any of them with the safe recipe: gcc -std=c11 -Wall -Wextra -Werror file.c -o app, then run ./app (Windows: ./app.exe).

    How to use: click View to open a file in the code viewer, read its comments, download it, compile it with the flags above, then modify it on purpose. The demos are ordered by lesson — start at 01 and work up.
