# C Roadmap

Sage-Code C programming tutorial — a complete, honest systems-language roadmap:

- **16 lessons** from language foundations (syntax, types, pointers) through memory
  management, data structures, algorithms, and advanced C (callbacks, bit
  manipulation, endianness, type punning).
- **20 single-file demos** in `demo/NN_name.c`, compiled safely with
  `gcc -std=c11 -Wall -Wextra -Werror`.
- **Study projects** (dynamic string builder, linked list with deletion,
  word-frequency counter) and a categorized **references & compilers** page.
- **8 track-specific SVG diagrams** in `img/` plus shared control-flow
  primitives; critical comparison of C with Zig and Oberon in `overview.html`.
