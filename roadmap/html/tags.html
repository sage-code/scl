Core Tags and Text Flow

This lesson focuses on the tags you will use most often in real pages: headings, paragraphs, lists, links, images, and basic containers.

Headings and paragraphs

Use headings to create structure and paragraphs for regular text. Do not skip heading levels without reason. 

<h1>Page title</h1>
<h2>Section title</h2>
<p>This is a paragraph of text.</p>

Inline text tags

Inline tags affect part of a sentence without creating a new block. 

<p>
  Learn <strong>important</strong> concepts and
  use <em>emphasis</em> where needed.
</p>
Prefer <strong> and <em> over purely visual tags when meaning matters.

Lists

Lists make information easier to scan.

Unordered list

<ul>
  <li>Install editor</li>
  <li>Create HTML file</li>
  <li>Open in browser</li>
</ul>

Ordered list

<ol>
  <li>Write structure</li>
  <li>Add content</li>
  <li>Validate output</li>
</ol>

Links and anchors

Links connect pages. Anchors jump to sections on the same page. 

<a href="/roadmap/html/index.html">Back to HTML roadmap</a>

<h2 id="faq">FAQ</h2>
<a href="#faq">Jump to FAQ</a>

Images and media basics

Always add useful alt text to informative images. 

<img src="/roadmap/html/img/ledy-bug.png" alt="Ladybug on a leaf">

Video can be embedded with the <video> tag. 

<video controls src="/roadmap/html/media/demo.mp4">
  Your browser does not support video.
</video>

Attributes you will use daily

  • id: unique identifier for links and scripts.
  • class: reusable style hook for CSS.
  • href: destination URL for links.
  • src: source URL for images/media/scripts.
  • alt: text alternative for images.

Containers: div and span

Use <div> for block grouping and <span> for inline grouping. Prefer semantic elements first (<section>, <article>, <nav>), then use <div> when no semantic tag fits.

Practice checklist

  1. Create a page with one <h1> and two <h2> headings.
  2. Add one ordered list and one unordered list.
  3. Add one internal anchor link.
  4. Add one image with clear alt text.
