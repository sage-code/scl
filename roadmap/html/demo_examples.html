    HTML Lab Examples

    Sixteen standalone demo pages that follow the track's lesson order, grouped by phase. Each demo is a complete, commented HTML file. Every row has two links: View code opens the source in the code viewer; Preview opens the rendered page in a new browser tab. Change one thing in the source, then reload the preview — that loop is where the learning happens.
