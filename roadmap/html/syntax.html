What is HTML?

HTML is the language that gives structure to a web page. It tells the browser what each part of the page means: title, paragraph, image, link, list, and more.

Think of HTML as the skeleton of a website. CSS handles style and JavaScript handles behavior, but HTML provides the base structure that everything else depends on.

Your first HTML document

This is the smallest useful HTML page:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My first page</title>
</head>
<body>
  <h1>Hello, web!</h1>
  <p>This is my first HTML page.</p>
</body>
</html>

How elements work

Most HTML elements have an opening tag and a closing tag. The content goes between them. 

<p>This is a paragraph.</p>

HTML element anatomy

Three common element types

Block elements

Block elements usually start on a new line and take full width. Examples: <h1>, <p>, <div>, <section>.

Inline elements

Inline elements stay inside a line of text. Examples: <strong>, <em>, <a>, <span>.

Void elements

Void elements do not have closing tags. Examples: <br>, <hr>, <img>.

Comments and formatting

Use comments for notes and explanations. Use indentation to keep code readable. 

<!-- This section contains contact info -->
<section>
  <h2>Contact</h2>
  <p>Email: hello@example.com</p>
</section>

Browsers collapse multiple spaces in normal text, so formatting your source code does not break the page.

HTML entities

Some symbols are reserved in HTML. Use entities when you want to display them as text.

Symbol Entity Meaning
< &lt; Less than
> &gt; Greater than
& &amp; Ampersand
" &quot; Double quote
(space) &nbsp; Non-breaking space

Inspect page source

Open any page, right-click, and choose View Page Source or Inspect. This is one of the fastest ways to learn how real sites are structured.
