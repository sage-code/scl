HTML References

This tutorial gives you a practical start; it is not the full specification. The categorized references below are the trusted sources to continue with — official standards, documentation, validators, and free practice environments.

Official documentation and standards

Reference What it is Best for Link
MDN Web Docs: HTML Element and attribute reference with examples and browser-compatibility notes. Day-to-day reference while learning and building. Open MDN HTML
WHATWG HTML Living Standard The continuously updated HTML specification browsers implement. Authoritative element behavior and parsing details. Open the Living Standard
W3C The standards organization publishing recommendations and guidance for the web platform. Understanding the standards process. Open W3C
Can I Use Browser compatibility tables for HTML, CSS, and JavaScript features. Deciding whether a feature is safe for your audience. Open Can I Use
Web Almanac HTTP Archive's annual state-of-the-web report with data-driven chapters. Seeing how real pages use HTML in production. Open Web Almanac

Validators and audit tools

Tool What it is Best for Link
W3C Markup Validator The official validator — URL, upload, or pasted source. Catching syntax, nesting, and content-model mistakes. Open the Validator
W3C CSS Validator Official validator for the stylesheets your pages load. Auditing the CSS that accompanies your markup. Open CSS Validator
Lighthouse Chrome DevTools audits for performance, accessibility, SEO, and best practices. Per-page quality gates before shipping. Open Lighthouse docs
axe DevTools Accessibility rule engine (browser extension and test libraries). Concrete a11y violations with element-level fixes. Open axe DevTools
Rich Results Test Google's structured-data and rich-result validator. Checking your JSON-LD (chapter 11). Open Rich Results Test

Accessibility references

Reference What it is Best for Link
WCAG 2 Overview The Web Content Accessibility Guidelines — the standard behind most a11y law. Understanding success criteria and conformance levels. Open WCAG Overview
ARIA Authoring Practices Guide Patterns for ARIA widgets with keyboard behavior and examples. Building custom widgets correctly (chapter 10). Open the APG
web.dev Accessibility Free course and guides from the Chrome team. Structured a11y learning with modern examples. Open Learn Accessibility
WebAIM Articles, checklists, and contrast tools from an a11y nonprofit. Quick checklists and contrast checking. Open WebAIM

Online practice environments

Environment What it is Best for Link
CodePen Browser editor with instant preview and shareable pens. Fast experiments without any local setup. Open CodePen
JSFiddle Multi-pane editor for HTML/CSS/JS with framework support. Testing markup with libraries attached. Open JSFiddle
StackBlitz Full development environments in the browser. Framework-based practice once you continue to the JS roadmap. Open StackBlitz

Free courses and books

Resource What it is Best for Link
MDN Learn HTML Structured modules with exercises and assessments. A guided path parallel to this track. Open Learn HTML
web.dev Learn HTML Google's visual, modern HTML course. Reviewing fundamentals with current platform features. Open Learn HTML (web.dev)

Suggested study plan

  1. Read the related MDN page for each topic in this roadmap.
  2. Practice by building the study projects from scratch.
  3. Validate each page with the W3C validator; audit with Lighthouse.
  4. When details differ from what you expect, check the Living Standard.
Practice and repetition are the key. The more HTML you write yourself, the faster you become and the less you depend on external tools.
