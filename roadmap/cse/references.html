    CSE is the foundations track: the vocabulary and concepts that make every other roadmap on this site easier to learn. It deliberately stays shallow on anything that has its own dedicated roadmap. This page is placed early in CSE on purpose — you don't have to finish the whole track first. Skim it now to see where CSE is heading, then either keep going topic by topic, or jump straight into whichever roadmap below already has what you're after.

    How to Read This Page

    Every engineering roadmap on this site is at a different stage of completion — some are fully written, some are actively growing. The Status column below is honest about that, so you know what to expect when you click through. A "Growing" track still has real, usable lessons; it just doesn't cover its full topic list yet.

    Core: Study These Next

    Two topics matter in every language and every project: how to organize data, and how to structure a program. Both get their own full roadmap instead of a CSE lesson:

    #RoadmapWhat It CoversStatus
    1 Data Structures & Algorithms Arrays, linked lists, stacks, queues, trees, graphs, hash tables, complexity analysis, searching, sorting, and algorithm design techniques (dynamic programming, greedy, backtracking). Growing — Data Structures is written; the algorithm lessons are next.
    2 Programming Paradigms Linear, structured, object-oriented, and functional programming, each as its own full lesson. Ready — all four lessons are written.

    Then: Pick a Language

    CSE and DSA/PGP teach concepts independent of any one language. At some point you need to actually write code — browse the full roadmap index and pick a language track that fits what you want to build. There's no wrong first language; the concepts you've just learned transfer to all of them.

    Suggested Order, Start to Finish

    1. Keep going with CSE — Dev Platforms, Tools, Version Control, Architecture, and the rest of the fundamentals.
    2. Data Structures & Algorithms and Programming Paradigms — the two direct extensions of what CSE teaches.
    3. Pick a language from the roadmap index and start building something real.
    4. Open Source Development — once you have code worth sharing, learn to collaborate on it properly.
    5. One or more specializations, based on where you want to end up: DBA for data, TechOps for deployment and operations, SML for data science, HPC for the hardware layer, DSL for language design.

    None of this is a strict prerequisite chain — you're reading this early on purpose, so jump ahead right now if something above grabs your interest sooner than the rest of CSE does. The order here just reflects what tends to build most naturally on what came before.
