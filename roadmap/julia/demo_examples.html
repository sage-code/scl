    Julia Lab Examples

    Twenty-one single-file programs, each short enough to read in a minute and complete enough to run. They follow the lesson order of the track: foundations first, then functions and scope, collections and types, and finally exceptions and files. Open a file, run it with julia file.jl, then change one thing and run it again — that second run is where the learning happens.

    Every example is self-contained: no package to install, no project to activate, nothing but the standard library. Where a lesson introduced a concept — implicit types, multiple dispatch, the type tree, lexical scope — there is a program here that shows it working, and one line you can break to see what happens when it is wrong.

    How to use these examples. Run each file straight from the track's demo folder — julia roadmap/julia/demo/01_variables.jl — or open it in the code viewer and copy it out. Files 5 and 6 read from standard input, so they expect you to type a character and press Enter. Nothing here needs a package, which makes this folder a good place to practise without touching a project environment.
