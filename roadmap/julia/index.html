Julia Tutorial

Julia is a general-purpose language built for technical computing. It reads like Python, runs like C, and was designed to erase the "two-language problem" — prototype and production code in the same language. This track takes you from your first script to enterprise-grade numerical, data, and scientific systems.

Scope: Study the topics in order, run every example in the Julia REPL, and connect each concept to the official documentation linked on the references page.
