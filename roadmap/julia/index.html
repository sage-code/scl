Julia Tutorial

Julia is a dynamic programming language for technical computing. It provides distributed parallel execution, numerical accuracy, and an extensive library. Julia is an interpreted language like Python but it has a JIT compiler that enables high-performance execution.

Scope: Study the lessons in order, run the examples in the Julia REPL, and revisit the index for targeted reference.
