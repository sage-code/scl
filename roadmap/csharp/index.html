C# Tutorial

C# is an advanced general purpose 3rd generation programming language. It is the default language for applications on the Windows and Azure cloud platforms. It was created in 2000 at Microsoft by Anders Hejlsberg.

Scope: Study the topics in order, run the examples in a .NET playground, and connect each concept to the Microsoft documentation.
