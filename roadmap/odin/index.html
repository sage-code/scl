Odin Tutorial

Odin is a general-purpose, statically typed, compiled language created by Ginger Bill in 2016 for modern systems programming. It favours simplicity and orthogonality over cleverness: no hidden allocations, no method tables, no exceptions — just explicit data, explicit memory, and code you can read top to bottom.

Scope: Study the topics in order, compile every example with the Odin toolchain, and treat the language overview as the authority when this track and your compiler disagree.
