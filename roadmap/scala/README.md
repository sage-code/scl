# Scala

A 16-topic Scala roadmap, progressing from language foundations through
composition, data & flow, structure & concurrency, to practice & reference —
covering the JVM, functional and object-oriented style, `Option`/`Try`/`Either`,
`Future`, and testing with ScalaTest/MUnit.

- `data/*.json` — sidebar sidecar files (one per topic page), consumed by
  `assets/js/topic-loader.js`.
- `demo/*.scala` — single-file practice programs, one per lesson, viewable
  through `/roadmap/code-viewer.html` and indexed on `demo_examples.html`.
