    References & Tools

    Everything you need to keep learning Scala for free: run code instantly in a browser, consult the authoritative references, follow guided courses, and read production Scala written by the community.

    Your own machine is still the best place to practice — every lab example runs with one scala-cli command. The tools below support that path at every level.

    How to Choose & Next Steps

    A short ladder that keeps you unblocked:

    • Finish every lab example on your own machine, then break and fix each one.
    • Work through Scala Exercises while reading the Scala 3 Book.
    • Keep Scastie open whenever you want to check one expression in isolation.
    • Read one file a day from Cats or Spark to see idiomatic, production-scale Scala.
    • Graduate to building something real — a backend service, a Spark job, or an Akka/Pekko actor system.

    You have reached the end of the Scala roadmap. The type errors that once slowed you down are now the reason your program compiles correctly the first time it runs.
