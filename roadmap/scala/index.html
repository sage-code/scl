Scala Tutorial

Scala is a multi-paradigm programming language created by Martin Odersky, blending object-oriented and functional programming. The first version was released in 2004, the second in 2006, and the third in 2021. Scala programs run on the JVM (Java Virtual Machine) and can use Java classes directly.

Scope: Study the lessons in order, run the examples on the JVM, and revisit the index for targeted reference.
