Scala Tutorial

Scala is a relatively new, multi-paradigm programming language created by Martin Odersky. The first version was released in 2004, the second in 2006, and the third in 2020. Scala programs run on the JVM (Java Virtual Machine) and can use Java classes.

Scope: Study the lessons in order, run the examples on the JVM, and revisit the index for targeted reference.
