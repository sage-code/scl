    Scala Demo Examples

    Practice programs, one file each. Every demo is self-contained, commented, and needs nothing but a JDK and scala-cli — see Setup & Toolchain.

    How to use: click View to open a file in the code viewer, read its comments, download it, then run it on your machine.

    scala-cli run 01_hello.scala    # compile and run a demo
scala-cli test 18_testing.scala # run the MUnit test demo
