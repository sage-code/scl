Nim Tutorial

Nim is a statically typed system programming language that focuses on safety and performance. It is a third generation language with features inspired from high-level languages: Python, Ada, and Lisp. It was created by a team led by Andreas Rumpf from Germany and is now ready for production projects.

Scope: Study the lessons in order, compile the examples locally, and revisit the index for targeted reference.
