    Nim Demo Examples

    Practice programs, one file each. Every demo is self-contained — copy it, modify it, run it. Each one imports only the standard library, so nothing else needs installing.

    How to use: click View to open a file in the code viewer, read its comments, download it to your machine, and compile it with the Nim toolchain. Most demos need only nim c -r <file>; the threads demo needs the default --mm:orc, and the build-modes demo is worth running three times with different defines.

    nim c -r 01_hello.nim                       # compile and run (debug build)
nim c -r -d:release 19_buildmodes.nim       # same source, optimized build
nim c -r 15_threads.nim                     # threads are on by default in Nim 2.x
nim c -r 16_interop.nim                     # links against libc (math.h, stdlib.h)
