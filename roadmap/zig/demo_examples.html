    Zig Demo Examples

    Practice programs, one file each. Every demo is self-contained — copy it, modify it, and run it. Each file @imports only the standard library, so nothing else needs installing.

    How to use: click View to open a file in the code viewer, read its comments, download it to your machine, and run it with the Zig toolchain. Most demos need only zig run <file>; the tests demo uses zig test.

    zig run 01_hello.zig     # compile and run
zig test 13_tests.zig    # compile and run the test blocks
