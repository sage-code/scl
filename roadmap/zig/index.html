Zig Tutorial

Zig is a blazing fast, statically typed, compiled systems programming language with a modern C-like syntax, offering low-level control, built-in memory safety, and powerful meta-programming capabilities. It prioritizes developer happiness with clear error messages, a friendly compiler, and an active community.

Scope: Study the topics in order, compile each example with the Zig toolchain, and use the official manual for authoritative depth.
