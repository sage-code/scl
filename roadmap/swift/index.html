Swift Tutorial

Swift is Apple's modern programming language for iOS, macOS, and server-side development. It combines safety, expressive syntax, and high performance. This course teaches the basics of Swift quickly and easily, even if you have no prior programming experience.

Scope: Study the topics in order, run the examples in a Swift playground, and use the official documentation for deep detail.
