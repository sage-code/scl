Swift Tutorial

Swift is Apple's modern, typed, general-purpose language introduced in 2014. It is the primary language for iOS, macOS, watchOS, and tvOS apps, and it also runs on Linux and the server. It combines safety, expressive syntax, and high performance.

Scope: Study the topics in order, run the examples in a Swift playground, and connect each concept to the official documentation.
