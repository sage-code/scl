    C++ Demo Examples

    Scope: Larger, self-contained practice programs — one file each. Every demo is fully commented so you can read why, not only what: open it in the code viewer, download it, build it, and change it.

    These demos go beyond the one-liners in the lessons — each combines several ideas into one working program you can break and fix. Only the standard library is used, so nothing extra needs installing. Build with any C++17 compiler: 

    # GCC or Clang
g++ -std=c++17 -Wall -Wextra 01_types_and_operators.cpp -o demo01 && ./demo01

# the concurrency demos (11, 12) need the threading library
g++ -std=c++17 -Wall -Wextra -pthread 11_threads_mutex.cpp -o demo11 && ./demo11

# on Windows with MSVC
cl /std:c++17 /EHsc 01_types_and_operators.cpp
