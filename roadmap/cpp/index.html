C++ Tutorial

C++ was created by Bjarne Stroustrup at Bell Labs starting in 1979 as an extension of C. It gives you direct control of memory and hardware while also supporting high-level abstractions such as classes, templates, and the standard library. C++ powers operating systems, game engines, databases, browsers, trading systems, and embedded devices — and it is taught here as a first programming language, with no C knowledge assumed.

Scope: Study the topics in order, compile every example yourself, and treat this track as a fast-forward — not as a reference manual. The modern C++ baseline is C++17, with C++20/23 features introduced where they matter.
