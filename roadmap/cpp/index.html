C++ Tutorial

C++ was developed by Bjarne Stroustrup at Bell Labs since 1979-1980 as an extension of the C language. It is considered safer than C but it can produce larger executable code and takes more resources to compile. C++ can be used to create high performance applications, server side services, desktop GUI applications, visual games, databases, and operating systems.

Scope: Study the lessons in order, compile each example locally, and treat this as a fast-forward not a reference manual.
