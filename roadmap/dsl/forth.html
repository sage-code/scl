    Forth

    Forth is a low-level, interactive, stack-based language created for embedded and real-time systems. It fits in a few kilobytes, drives machinery with deterministic timing, and its postfix style changes how you think about programs.

    Purpose

    Forth occupies the hardware-near end of the language spectrum: a small, extensible language for programming machines directly — microcontrollers, firmware, boot code — with no large runtime underneath.

    The Problem It Solves

    Embedded developers need three things at once: tiny memory footprints (RAM and ROM measured in kilobytes), interactive development (test a word the moment it is written), and direct hardware access. Forth delivers all three. It uses a data stack and postfix (Reverse Polish) notation, and it grows through a dictionary of words: you define new words from old words, extending the language toward your problem instead of rewriting it.

    Where It Fits

    Forth sits between assembly and C. It is more productive than assembly because you compose small, testable words interactively, and leaner than C because there is no hidden runtime, heap, or startup code. It is a general-purpose language by design, but its domain-specific niche is exactly the low-level world this phase studies.

    History

    Forth is one of the oldest living languages, and every step of its history is tied to hardware control.

    Origins (1968–1973)

    Charles H. Moore developed the first working Forth while controlling radio telescopes at the US National Radio Astronomy Observatory (1968–1970). The name truncates “fourth” to five characters (the keyboard accepted only five) for a “fourth-generation” language. Moore and Elizabeth Rather founded Forth Inc. in 1973 to sell it commercially.

    Milestones

    • 1978 — FIG-Forth, a free model implementation that spread Forth to hobbyists worldwide.
    • 1994 — ANSI standard X3.215-1994 (maintained today at forth-standard.org) fixed a common core every implementation shares.
    • 1994+ — Open Firmware (IEEE 1275-1994), written in Forth, booted Sun workstations and PowerPC Macintoshes.
    • 1998–2014 — Forth flew on NASA’s Deep Space 1 and ESA’s Philae comet lander, where small deterministic code was a survival requirement.

    Current Status

    Niche but alive. ANS Forth remains the common core; standards work continues; Gforth (GNU) and Mecrisp Stellaris serve open-source users, while Forth Inc. sells SwiftForth and SwiftX for professional firmware teams.
