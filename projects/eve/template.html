Eve Language Tutorial

Start a new tutorial page from this file: copy it to name.html, replace the title, the h1 and the id of the sections, and write the sidebar file data/name.json (one entry for the h1, one for each h2 with its h3 sections as children). Keep one h1, and give every h2 at least one h3.

Section

One idea per paragraph. Write names in code with <code>; write < and > inside code as &lt; and &gt;.

Example

#! free script
** example: comments start with two stars
driver name is
  process main is
    print "Hello";
  return;
end name;

Output:

Hello
