Eve Manifest

Eve is a domain-specific, modular programming language, designed for productivity and ease of learning. It is used for data processing and test automation: text data, binary data (like images and video streams), and database connectivity.

Virtual Machine

Eve is a multi-paradigm scripting language that runs on its own virtual machine. The machine is a stand-alone program, written in Zig. It does not depend on other languages or libraries: the standard library is built from scratch, with a "batteries included" approach.

Operational Capabilities

The standard library targets these goals:

  • Data Compression: reduces data for storage and transmission.
  • Database Synchronization: keeps databases consistent in both directions.
  • Data Curation: cleans raw data.
  • Data Encryption: protects data in storage and in transit.
  • Archiving & Restoration: backup and recovery.

Key Features

Eve language is inspired from Ruby, Ada, Python, Go and Java. It is easy to grasp like Python but has type checking like Java. It is a multi-paradigm language, hybrid: Procedural, Functional and Object Oriented. We can say EVE is a "Process Oriented Language".

  • Readable Syntax

    Eve uses familiar keywords and syntax. It employs an explicit, consistent, and verbose style for enhanced code readability and learning by example. Additionally, Eve supports syntax highlighting and colorization for improved code comprehension.

  • Effective and Productive

    Eve is tailored towards domain-specific jobs, prioritizing developer productivity. It focuses on effectiveness over extreme efficiency or high-performance computing.

  • Type-Safe by Design

    Eve has a gradual type system: some type errors are reported at compile time, some at run time. Basic types are initialized with zero values, and a missing value is the explicit Null.

  • Modular Architecture

    Eve encourages code reusability through scripts and modules, promoting separation of concerns in larger projects. It offers three module types:

    • Drivers: Serve as executable entry points for your programs.
    • Aspects: Represent individual processes launched from drivers and unloaded from memory upon completion.
    • Modules: Provide reusable but non-executable components that persist until the driver finishes.

  • Versatile Data Handling

    Eve will be able to connect and manipulates data from various databases. It reads and writes diverse data formats, including text, images, and video streams. We will create specific drivers for each database we interact with and optimize data access for reliability and performance.

Code Example

This Eve program calculates the 5th number in the Fibonacci sequence. Here's a breakdown:

# Fibonacci series demonstrate
driver fibonacci is

  ** declare Fibonacci method
  function fib(n:Integer) => (@y:Integer) is
    if n < 2 do
      y := n; ** fib(0) = 0, fib(1) = 1
    else
      y := fib(n-1) + fib(n-2);
    done;
  return;

  process main is
    ** local variable for result
    ** call fib function using argument 5
    let r := fib(5);

    ** print the result to console
    print r;
  return;
end fibonacci;

Explanation

  • Driver and Function Definition:
    • The line "driver fibonacci is" declares the main program named "fibonacci".
    • The line "function fib(n:Integer) => (y:Integer)" defines a function named "fib" that takes an integer "n" as input and returns an integer value.
  • Recursive Calculation:
    • The "fib" function uses recursion to calculate the nth Fibonacci number.
    • The "if" statement checks if "n" is either 1 or 0, which are the base cases in the sequence (fib(0) is 0, fib(1) is 1).
    • The "else" block calculates "fib(n)" using the values of "fib(n-1)" and "fib(n-2)", demonstrating recursion.
  • Main Program Execution:
    • The "process" block defines the main execution flow.
    • The line "let r := fib(5);" declares the variable "r", calls the "fib" function with "5" and assigns the result (5) to "r".
    • The "print r;" statement displays the calculated value to the console.

Implementation Grant

To remove any doubt about whether writing a compiler from a written grammar is allowed, the specification carries an explicit grant permitting implementations:

Trademark & Compliance

Copyright protects the wording of the specification; trademark protects the name "EVE" and the logo, which belong to Sage-Code Laboratory, and keeps the ecosystem from splitting into incompatible dialects, the way Oracle stewards Java or the Rust Foundation stewards Rust. The full policy is the file TRADEMARK.md of the repository.

  • Allowed: anyone may write "Built for EVE", "EVE compatible" or "Based on the EVE language specification" to describe their own product, if it is true.

  • Compliance requirement: an implementation may only call itself an "EVE Compiler" or claim to be "EVE Compliant" if it passes the official conformance test suite or strictly adheres to the published specification.
  • Incompatible implementations: modified or extended dialects must not be presented as official EVE and should instead describe themselves as "based on the EVE language specification".
