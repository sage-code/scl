Eve Performance

A small benchmark for each level, with a twin in Python. They are not conformity tests: they check that the machine stays fast while features are added. The report compares each run with the last saved one, and the ratio Eve / Python shows an accidental slowdown. Run them with python script/bmark.py (add --save to record a run). Compare only runs of the same build on the same machine.
