EVE Programming

Master Eve - a data-centric DSL built for internet ETL pipelines, with a gradual typing JIT compiler and virtual machine, and one syntax for data transforming and routing between a local client and a server backend. This laboratory guides you through 29 topics, from the syntax to the compiler.
