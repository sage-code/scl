Eve Optional Symbols

Eve accepts a set of optional symbols that can be used inside expressions and literals. They are not keywords, so they can be typed directly from the keyboard or pasted from a symbol palette.

Available Symbols

The following symbols are recognized by the Eve lexer. They are optional: every one of them has an ASCII alternative, so a script can stay portable across keyboards and encodings.

≠ ≤ ≥ ÷ ≈ ø π ¬ ± ^ • ¶ § ∞ √ ∫ Ω µ ∆ ∂ ∑ ∏

Usage

Optional symbols are interchangeable with their ASCII equivalents. Use them when they improve readability; keep the ASCII form when the source must survive a plain-text round trip.

Example:


# optional symbols in an expression
process
  new a := 10;
  new b := 3;

  ** the two lines below are equivalent
  print a ≠ b;   ** true
  print a <> b;  ** true
return;
