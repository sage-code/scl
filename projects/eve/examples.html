Eve Demos & Examples

One demo for every chapter of the tutorial, with the representative features of the chapter. Open a source in the code viewer: every demo is one file, except the module demo, which is a small project. A demo that needs a driver and its aspects is an Eve macro: the aspects and the driver are in the same file. The column Runs says whether the Eve virtual machine runs the demo today; a preview shows the syntax of a later level. The conformity tests are on the Feature Tests page.
