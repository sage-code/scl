Eve Smoke Test & Performance

The checks of the machine that are not feature tests. The smoke test is the quick check that the machine and the language are sane: each script is a driver with small functions and very simple expect lines, True is True, 0 == 0. It does not depend on the feature tests, and it shows that the program compiles, parses and has no contradiction. The performance benchmarks check that the machine stays fast while features are added: each has a twin in Python, and the history of the runs shows every change.
