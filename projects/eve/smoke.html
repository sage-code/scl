Eve Smoke Test

The quick check that the machine and the language are sane. Each script is a driver with small functions and very simple expect lines, one feature each: True is True, 0 == 0. It runs in less than a second, does not depend on the tests of the levels and shows that the program compiles, parses and has no contradiction. Run it with python script/runtest.py smoke.
