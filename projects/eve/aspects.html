Eve Aspects

An aspect is an encapsulated machine that a driver applies or starts. Every aspect says what it is: exclusive or concurrent.

Aspects

An "aspect" is a script specific to a particular project. It resolve a problem or address a specific concern. Aspect files are executable. An aspect is an independent, encapsulated machine with the same shape as a driver: declarations and one process main, its entry point, that receives the parameters of the aspect. An aspect can't apply or start another aspect, so processes can not be recursive; methods can.

An aspect is not instantiated and has no public members: the dot operator is never used with an aspect. Data goes in by the parameters of main and comes out by its output parameters (@). Each call creates the state of the aspect, and the state is dropped when main returns. An aspect is executed with the keyword "apply", in serial mode. Aspects applied in sequence can raise errors like any other process, and the error propagates to the caller. An error that nobody handles ends the application. The driver captures the exit code of panic, raise, expect and assert.

Every aspect declares what it is. An exclusive aspect is run only in serial mode, with apply: it may use any function and any module, and it can never be started. A concurrent aspect may also be started in a parallel group, so the compiler checks it where it is written and fails if it can reach a function that is not thread safe (see Thread safety). A script that says only aspect is an exclusive aspect: exclusive is the default, and concurrent has to be written.

Aspect skeleton:


** purpose of the aspect: write "exclusive" or "concurrent" before "aspect"
concurrent aspect aspect_name is

  ** declarations of the aspect: private, created at each apply
  ** and dropped when main returns; an aspect defines no globals
  new count = 0 :Integer;

  from $path/library_name use (*);

  ** helper work is done by functions
  procedure helper(parameter_list) is
    ...
  return;

  ** the only process: the entry point
  process main(parameter_list) is
    ** executable region
    ...
  recover
    ** handle all errors
    ...
  finalize
    ** release locked resources
    ...
  return;
end aspect_name;
