Eve System Library

The Standard Library is what every program has without an import: the built-in functions and the standard streams. The System Library is the set of modules that connect a program to the machine around it: the console, the file system, the clock, the shell and the network. A module of the system library is imported with from … use, like any other module, from $EVE_LIB.
Status: the built-in names need no import and are complete for level 1. The modules of level 5 (fs, time, os, secret, csv, json, txt, crypto, net, database) and the modules of levels 6 and 7 (http, route, service, rpc) are designed and specified; their members are still being completed. Only the members called by a test are listed in the specification.

The standard modules are in scope in every script without an import: write fs.read!(path), csv.read!(:Order)(path) or database.connect("sales") directly. A project module with the name of a standard module is a compile error. A Secret is made with Secret(text) or secret.get(name), and prints as ***.

Compressed files

A path that ends in .gz is a gzip file for the readers and the writers of csv, json, txt and for fs.lines!: the file is compressed when it is written and inflated when it is read, and a file that is not gzip is a FormatError. gzip.write(path, data) writes a String or Bytes; gzip.open!(path) gives the content as a stream of Bytes, which a reader accepts in place of a path. A zip archive keeps many entries: zip.write takes a map of names to String or Bytes, zip.list! gives the sorted names and zip.read! one entry as Bytes; a missing name is FileError. An archive does not hold a clock, so the same entries give the same bytes. The files are processed whole, in memory, and an archive over 4 GB or with more than 65,535 entries is not supported.


primary aspect archive is
  class Item = {name: String, qty: Integer} <: Record;

  process main is
    new items := (Item(name: "bolt", qty: 4), Item(name: "nut", qty: 9));
    csv.write("out/items.csv.gz", items);                       ** compressed on the fly
    for r in csv.read!(:Item)(gzip.open!("out/items.csv.gz")) do
      print "{r.name} {r.qty}";
    done;
    zip.write("out/pack.zip", {"items.csv": "name,qty;bolt,4", "note.txt": "two items"});
    for name in zip.list!("out/pack.zip") do
      print name;
    done;
    print zip.read!("out/pack.zip", "note.txt").text();
  return;
end archive;

Statistics

The library stats is written in Eve, in the folder lib/stats. from lib use (stats); gives the descriptive functions (mean, median, mode, modes, variance, stddev, quantile, range, skew, kurtosis, describe), the correlations (covariance, pearson, spearman) and the modules regress, distrib, sample, histogram and moving. The sample forms of the variance and the deviation divide by n - 1 (Excel VAR.S); the population forms have the suffix _p. A list that is empty, too short or not made of numbers is ArgumentError.


primary aspect numbers is
  from lib use (stats);

  process main is
    new xs := (2, 4, 4, 4, 5, 5, 7, 9);
    print stats.mean(xs), stats.median(xs), stats.modes(xs);       ** 5 4.5 (4)
    print stats.stddev_p(xs);                                      ** 2
    new d := stats.describe(xs);
    print d["count"], d["min"], d["max"];                          ** 8 2 9
    new line := stats.regress.linear((1, 2, 3, 4, 5), (2.2, 4.1, 6.2, 7.9, 10.1));
    print line["slope"], line["intercept"], line["r2"];            ** 1.96 0.22 0.9988...
    print stats.distrib.norm_cdf(1.96, 0, 1);                      ** 0.975...
    print stats.moving.simple((1, 2, 3, 4, 5), 3);                 ** (null,null,2,3,4)
    for b in stats.histogram.bins((1, 2, 2, 3, 9, 10), 3) do
      print "{b.low} {b.high} {b.count}";                         ** 1 4 4, 4 7 0, 7 10 2
    done;
  return;
end numbers;

Rules of the system library

  • Written in Eve. A module is Eve code. Only the few primitives that need the machine are external declarations, implemented by the virtual machine in Zig (see EVE VM);
  • Errors are values of the language. A module raises the errors of the exception module, so one recover region handles them all;
  • Thread safety is declared by the compiler. A function of a module is thread safe only if it keeps no plain shared variable; a concurrent aspect can call it only then (see Thread safety);
  • Documented from the code. eve --doc builds the reference of a module from its ** comments and signatures.

Example

The built-in names are always available. The example below reads a name and writes a line; it uses only the standard streams.


# ask a name and greet
primary aspect greeting is
  process main is
    new name := read("name: ");
    if name <> null then
      print "Hello,", name;
    else
      print "Hello, stranger";
    done;
  return;
end greeting;
