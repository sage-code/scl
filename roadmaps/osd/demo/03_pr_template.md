# Pull Request Checklist

## Summary
- Explain *what* changed and *why* (link the issue: `Closes #123`).

## Verification
- [ ] Unit/integration tests added or updated.
- [ ] Documentation and inline comments updated where behavior changed.
- [ ] Local build and linter pass with zero new warnings.

## Reviewer Notes
- Call out any risky migrations, breaking API changes, or follow-up tasks.
